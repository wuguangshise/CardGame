## 怎么玩

需要 Python 3.10 或更新版本。

### Windows / Conda / 编辑器启动

```bash
conda create -n cardgame python=3.12 -y
conda activate cardgame
python -m pip install -r requirements.txt
python start.py                 # 默认图形版
python start.py --cli           # 命令行版
python start.py --check         # 查看实际 Python 路径并检查依赖
```

Windows 推荐双击 `start_game.bat`（图形版）或 `start_cli.bat`（命令行版）。
脚本会切换到游戏目录；检测到 conda 时使用 `cardgame` 环境，否则使用系统 Python。
运行结束或报错后窗口会保留。`play.py` 是纯命令行版，`play_gui.py` 是图形版，旧启动命令继续可用。
不要只拷贝一个 play 文件：需要保留 `shuangshengwen/` 和 `assets/` 等完整目录。

VS Code / PyCharm 请选择 `cardgame` 环境的 Python，直接运行 `start.py` 或 `play_gui.py`。
命令行版需要可交互终端，不适合禁止标准输入的输出面板。
未捕获的错误会显示当前 Python 和依赖安装指令，并记录到 `logs/startup_error.log`（目录不可写时保存到系统临时目录）。

### 图形版（推荐）

```bash
python3 -m pip install pygame-ce   # 只需要装一次
python3 play_gui.py                # 你 vs 人机
python3 play_gui.py --no-timer     # 关掉每回合 30 秒计时
python3 play_gui.py --advanced     # 抢先手、亮牌禁牌
python3 play_gui.py --deck decks/warrior.json  # 自定义套牌
python3 play_gui.py --no-animations  # 关闭动画
```

操作参考炉石传说，全部用鼠标拖：

| 想做什么 | 怎么操作 |
| --- | --- |
| 打出一张牌 | 把手牌拖到场地中间 |
| 合纹 | 把附加卡拖到主卡上（手牌里的另一张） |
| 召唤纹兽 | 把红牌、绿牌先后拖到同一个纹兽位 |
| 进化纹兽 | 点纹兽左上角「升级」或右键纹兽，选择纹牌并确认献祭；也可把素材纹兽拖到保留的纹兽上，或把纹牌拖到目标纹兽上 |
| 铺纹域 | 把牌拖到纹域位；蓝牌拖到已生效的纹域上可以选续命 |
| 防御纹 | 把牌拖到防御纹盖牌；点击防御纹翻开 |
| 弃牌献祭 | 把手牌拖到「弃牌献祭」台，只获得 +1 纹力，不升级纹兽 |
| 攻击 | 从自己的角色或纹兽按住拖出箭头，松开在敌方角色、纹兽或纹域上 |
| 结束回合 | 点「结束回合」或按空格 |

对方攻击时会弹出 8 秒判定，8 秒内不选就默认「都不用」。右键取消拖动。

纹兽升级必须有两只纹兽，其中献祭素材必须是1级。1→2级消耗纹牌但不扣纹力；2→3级需要再次召唤一只1级素材，并支付纹牌原价。
确认窗口会注明保留谁、献祭谁、消耗哪张牌及费用；取消或费用不足不会消耗卡牌、素材或纹力。

### 命令行版（不用装 pygame）

```bash
python3 play.py              # 你 vs 人机
python3 play.py --hotseat    # 两个人在同一台电脑上轮流玩
python3 play.py --seed 42    # 固定随机种子，复现同一局
python3 simulate.py 1000     # 电脑对电脑跑 1000 局，看胜率和对局长度
python3 -m unittest discover -s tests -t .   # 跑测试
```

每回合会显示双方场面和你的手牌，输入数字选操作，输入 0 结束回合。
对方攻击你时会弹出「8 秒判定」（命令行版不计时），选择纹兽挡刀、紧急举盾或都不用。

## 测试版做了什么

- 赛前：默认选职业、随机先后手；`--advanced` 保留抢先手、亮牌（先手5张、后手4张）、各禁2张。
- 套牌：每套32张，同名最多2张，允许自由配色。战士红14/绿10/蓝8，守护者红10/绿14/蓝8，大魔导师红10/绿10/蓝12。职业预组各重复一张组合组件（裂风/青藤/秘法盾），连击、灵感、法力回流等仍是单张。
- 自定义：复制 `decks/` 中的JSON文件修改卡名，使用 `python start.py --deck 路径.json` 或 `python start.py --cli --deck 路径.json`。文件是32个卡名的列表，程序会检查数量、重复上限与未知卡名；人机使用自己的职业预组。当前通过文件构筑，尚无图形套牌编辑器。
- 纹力12起步；从各自第2回合开始，每回合恢复1点，剩余继续累积；献祭+1。手牌上限（回合结束 5 张，回合中 8 张）、抽空后伤害翻倍。
- 合纹、红绿召唤纹兽（可分两回合盖着放）、进化（2 级免费、3 级付费、3 级保持 2 回合）。
- 纹域（第一张定类型、第二张定配合，耐久 = 纹值之和，可覆盖、可被打、可续命）。
- 防御纹（不能放红牌、每回合 -1 费最多 -2、紧急举盾两倍费用）。
- 三个职业都是 1 攻 15 血，被动：战士每回合第一张红牌 -1 费，大魔导师「法术连锁」（本回合第1张蓝牌原价，第2张起减1费，减费最多1；打出第2张时连锁爆发，对方角色受1伤害，无视护盾，不额外抽牌），开局多 1 纹力，守护者的护盾多挡对方 1 个回合。
- 先攻 / 后发关键词。后手开局多 1 纹力（抵消先手优势）。

## 测试版自己补的细节（规则书里还没写，测试时留意）

- **护盾持续时间**：护盾挡对方接下来 1 个回合，到自己下回合开始消失（守护者挡 2 个）。攻击加成按自己的回合算，「持续 2 回合」就是能用在两次攻击上。
- **刚召唤的纹兽**下回合才能攻击。
- **进化收益**：继承素材当前攻、血的一半向上取整，攻血各至少1点；红纹额外+1攻，绿纹额外+2血，蓝纹获得穿透；进化获得1护盾。
- **3级觉醒**：再获得临时+1攻/+1血，清除封印，额外获得2护盾，保持2个自己的回合；不重置攻击次数，也不解除召唤休整。退化保留累计伤害，伤势超过2级最大生命时会倒下。
- **封印**：阻止纹兽在下一个自己的回合攻击，到该回合结束解除。
- **攻击表现**：卡牌先抬起显形，随后发射带拖尾的纹能；纹兽以本体残影扑击。实际挡刀目标会接住特效，命中有闪光、局部震动、格挡/伤害数字，死亡纹兽也保留命中反馈。召唤、进化、3级觉醒有独立光效。
- **纹域效果**：战意（红）加攻击、守护（绿）每回合加护盾、秘法（蓝）每回合燃烧 / 回血 / 多抽；两张合计 6 费的纹域数值 +1。
- **附加卡特性**：红 = 本回合角色攻击最多穿透2点护盾，重复附加不叠加；绿 = 护盾；蓝 = 随机抽牌 / 吸血 / 燃烧。绿和蓝的数值都是纹值的一半向上取整（护盾等于纹值时附加卡等于白送护盾，对局会拖成乌龟局）。
- **法术伤害**：奥术飞弹、魔力风暴无视护盾，否则守护者对大魔导师胜率太高。
- 职业的 KO 专属牌还没做。命令行版没有 30 秒计时，图形版有。

## 平衡测试

`python3 simulate.py 100 --seed 2003 --workers 8 --json /tmp/balance.json` 跑9种有序职业组合，每种100局，总计900局；统计配对胜率、先手胜率、平均长度、超时，以及召唤/进化/献祭使用次数。

`python3 simulate.py 20 --level strong --seed 1009` 使用两步搜索人机检查爆发打法；`--advanced` 测禁牌模式。`python3 simulate.py 5 --skill` 检查新手与高手人机差异。固定种子同时控制洗牌和人机试算，结果可复现。

人机每一步在副本上试算，不触发真实画面的动画。防御判断会考虑实际穿透、纹兽挡刀、抽空伤害翻倍与紧急回复。人机结果不能替代真人平衡结论，尤其两步搜索仍不擅长长线防御与诈唬。详细参数和实验结果见 [BALANCE.md](BALANCE.md)。

[查看战斗动画预览](docs/battle-preview.gif)。动画预览可用 `python tools/preview_battle.py --output /tmp/battle.gif` 在无窗口环境录制。它调用实际GUI表现事件，包含击杀、燃烧、纹兽攻击、2级进化与3级觉醒。

## 美术

美术采用古老传说感的日漫手绘风格：清晰线稿、平涂上色、少量阴影。
正式插画位于 `assets/`，包含40张卡面、9种透明纹兽、3个职业头像，以及9张背景与界面素材。
提示词和文件命名规则见 [ART_PROMPTS.md](ART_PROMPTS.md)，逐项完成状态见 `assets/art_manifest.json`。
启动游戏即可加载；缺图时保留程序占位图。纹兽进化纹路、背景飘叶与微光、伤害斩击和治疗波纹由程序绘制。
卡牌文字与数值由程序绘制，插画不含文字。可执行 `python tools/check_art.py` 检查全部素材（需要Pillow）。

## 代码结构

```
shuangshengwen/cards.py      卡牌数据（改数值只需要改这里）
shuangshengwen/engine.py     规则引擎，不含输入输出，以后搬到 Godot 照着改
shuangshengwen/ai.py         人机（每一步在副本上试算，挑局面最好的动作）
shuangshengwen/gui/app.py    图形界面：拖放、弹窗、计时
shuangshengwen/gui/art.py    程序绘制的美术
shuangshengwen/gui/effects.py  发射、飞行、残影与命中特效
play_gui.py                  图形版入口
play.py                      命令行版入口
simulate.py                  批量模拟
assets/                      放正式插画的地方
```
